
FlatSync Expense Manager - Full Working MERN Project

==============================
Frontend Setup
==============================
1. Open terminal
2. cd frontend
3. npm install
4. npm run dev

==============================
Backend Setup
==============================
1. Open terminal
2. cd backend
3. npm install
4. Create .env file
5. Add MongoDB URI
6. npm run dev

==============================
Features Included
==============================
- User Authentication
- Expense Management
- MongoDB Integration
- Responsive UI
- REST APIs
- Dynamic Expense Rendering
